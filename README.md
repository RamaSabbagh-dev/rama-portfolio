# Rama Portfolio

Vanilla HTML, CSS and JavaScript implementation of the portfolio concept.

## Run

Open `index.html` directly in a browser, or run a local server such as VS Code Live Server.

## Files

- `index.html` - page structure
- `style.css` - layout, responsive design and visual styling
- `script.js` - mobile navigation and reveal-on-scroll behaviour
- `assets/rama.photo.png` - portrait
